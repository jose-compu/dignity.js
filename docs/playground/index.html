Live playground

Pick a feature, edit the code on the left, and run it in your browser. Demos use the bundled dignity.esm.js with an in-memory mesh (InMemoryNetworkHub) — no server or PeerJS required.

Examples: identity · live streaming · access modes · WebRTC signaling · private chunks · combined + rotation · verification policies · app manifest · stored command · CRUD basics · 3D chess · tic-tac-toe

New in v1.8.0 (package 1.8.0): Node private/combined stream origin — see examples/node-private-stream-origin.js (npm run example:node-private-stream). Browser demos below stay on the main bundle.

Streaming from v1.6.0: combined public/private streams and sender-key epoch rotation — createPrivateSenderKeyEpoch, rotatePrivateSenderKeyEpoch — plus v1.5.x private chunk sealing in the Live streaming dropdown.
